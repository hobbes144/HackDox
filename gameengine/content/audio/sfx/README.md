# Placeholder SFX

Every `.wav` in this folder is a synthesized placeholder generated by
`../generate_placeholders.py` — simple sine tones, sweeps, and clicks,
chosen only to be audibly distinct per trigger so testing has *something*
to listen to. None of it is meant to ship.

To replace one with real audio: drop a new file at the **same filename**
(e.g. `verdict_correct_accept.wav`) — `gameengine/core/audio.py`'s
`SFX_REGISTRY` and every call site key off the sound *id*, not the file,
so nothing else needs to change. Mono or stereo, any sample rate pygame's
mixer supports (44.1kHz/16-bit is what the generator writes).

To add a brand new trigger point: add an id -> filename entry to
`SFX_REGISTRY` in `gameengine/core/audio.py`, drop a file here (or a quick
recipe in `generate_placeholders.py` to placeholder it), and call
`sound_manager.play("your_new_id")` at the trigger site.
